# 🚀 CareerConnect Frontend — Next.js 16 Client

This is the Next.js frontend client for **CareerConnect** — a full-stack job portal built with Next.js 16, React 19, TanStack Query v5, and Tailwind CSS v4.

👉 **View Full Project Documentation**: [Root README.md](../README.md)

---

## 🛠️ Client Tech Stack

- **Framework**: Next.js 16 (App Router) & React 19
- **Data Caching & State**: TanStack Query v5
- **Styling**: Tailwind CSS v4 & Lucide React Icons
- **Auth Integration**: Firebase Authentication & JWT HttpOnly cookie sync
- **Notifications**: Sonner Toast

---

## ⚡ Quick Start

```bash
# Install dependencies
npm install

# Run local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.
